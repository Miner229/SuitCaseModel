# Чемодан.kz — сайт-каталог чемоданов

Каталог с фильтрами, карточками товаров, региональными страницами под 18 городов Казахстана, заявками в Telegram и админ-панелью.

**Стек:** PHP 8.1+ (без фреймворков и Composer), MySQL 5.7+ / MariaDB 10.4+, чистый CSS/JS (без jQuery и внешних шрифтов).
Работает на обычном shared-хостинге с Apache или на VPS с nginx.

## Структура

```
public/            ← КОРЕНЬ САЙТА (document root). Только это доступно из интернета
  index.php        front-controller: роутинг, нормализация URL
  assets/          CSS, JS, иконки
  uploads/         фото товаров (WebP), выполнение скриптов запрещено
  .htaccess        HTTPS, www→без www, ЧПУ, кэш, gzip
app/
  routes.php       публичные страницы, sitemap, robots, API
  admin.php        админ-панель
  lib/             БД, безопасность, SEO, каталог, заявки, Telegram, изображения
  views/           шаблоны (страницы, админка, информационные страницы)
database/schema.sql
bin/install.php    установка: таблицы + демо-данные + администратор
deploy/nginx.conf  пример конфигурации для VPS
tests/             автотесты (см. TESTING.md)
.env               настройки сервера и секреты (создаётся из .env.example)
```

## Установка на хостинг

> ⚠️ **Хостинг в Казахстане.** По Закону РК «О персональных данных и их защите» база, где хранятся заявки (имена и телефоны), должна находиться на территории РК. Выбирайте хостинг с серверами в Казахстане (ps.kz, hoster.kz и т.п.).

1. Создайте в панели хостинга базу MySQL (кодировка `utf8mb4`), пользователя с паролем.
2. Загрузите файлы проекта. **Корнем сайта (document root) укажите папку `public/`.**
   Если хостинг не позволяет — оставьте как есть: корневой `.htaccess` сам направит запросы в `public/` и закроет остальные папки.
3. Скопируйте `.env.example` → `.env` и заполните:
   - `APP_URL=https://ваш-домен.kz` — основной адрес (без www, если главное зеркало без www);
   - `APP_ENV=production`, `APP_DEBUG=0`, `APP_FORCE_HTTPS=1`;
   - `DB_*` — доступы к базе;
   - `APP_SECRET` — случайная строка 64 символа (`php -r "echo bin2hex(random_bytes(32));"`);
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — см. ниже.
4. Выполните по SSH (или через «Cron/консоль» в панели хостинга):
   ```bash
   php bin/install.php --admin=admin
   ```
   Скрипт создаст таблицы, 20 демо-товаров, 18 городов и выведет пароль администратора.
   Без демо-товаров: `php bin/install.php --no-demo`.
5. Включите SSL-сертификат (Let's Encrypt) в панели хостинга.
6. Проверьте сайт: `php tests/postdeploy.php https://ваш-домен.kz` — см. TESTING.md.

Требования PHP: расширения `pdo_mysql`, `gd` (с поддержкой WebP), `curl`, `mbstring`, `fileinfo`, `intl` не обязателен.
Для загрузки фото: `upload_max_filesize ≥ 10M`, `post_max_size ≥ 40M`. Отключите `expose_php`.

### Telegram-уведомления

1. В Telegram напишите @BotFather → `/newbot` → получите токен вида `123456:ABC...`.
2. Создайте группу для заявок, добавьте в неё бота и любого сотрудника.
3. Напишите в группе любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — найдите `"chat":{"id":-100...}`.
4. Впишите токен и id в `.env`. В админке: **Настройки → Отправить тестовое сообщение**.

Токен хранится только в `.env` на сервере — не в базе и не в коде. Если Telegram недоступен, заявка всё равно сохраняется в админке.

## Админ-панель — `/admin/`

| Раздел | Что можно делать |
|---|---|
| **Обзор** | новые заявки, товары без фото, предупреждения (нет Метрики, не настроен Telegram) |
| **Товары** | добавить / изменить / дублировать / удалить товар; цены, старая цена (скидка), наличие, показ на сайте прямо в списке; фото (несколько сразу, порядок, alt), характеристики, описание, SEO-поля |
| **Заявки** | все заявки с телефоном, товаром, страницей, UTM-метками и фактом согласия на обработку ПД; статусы и заметки; выгрузка в Excel (CSV) |
| **SEO** | title, description, H1 и тексты категорий и городских страниц, включение/выключение городов |
| **Настройки** | контакты, WhatsApp, Telegram, номер Яндекс Метрики, коды Вебмастера и Search Console, задержка попапа |
| **Пароль** | смена пароля (мин. 10 символов, буквы и цифры) |

Фото можно загружать любыми (JPG/PNG/WebP до 10 МБ) — сайт сам сожмёт их и сделает 3 размера в WebP.
Рекомендуется квадратное фото на светлом фоне, от 1200×1200 px.

## Локальная разработка

```bash
cp .env.example .env    # APP_ENV=development, APP_FORCE_HTTPS=0, APP_URL=http://localhost:8000
php bin/install.php --admin=admin --password=TestPass12345
php -S localhost:8000 -t public public/router.php
```

## Безопасность (что сделано)

- Все SQL-запросы — подготовленные выражения (PDO), весь вывод экранируется (XSS).
- CSP с nonce, HSTS, X-Frame-Options/frame-ancestors, nosniff, Referrer-Policy, Permissions-Policy.
- Админка: пароли bcrypt, CSRF-токены на всех действиях, cookie `HttpOnly + Secure + SameSite=Strict`, регенерация сессии при входе, таймаут 2 часа, лимит попыток входа (5 за 15 мин с IP, 20 в час на логин), `noindex`.
- Формы: подписанный HMAC-токен (защита от CSRF и мгновенной отправки ботом), honeypot-поле, проверка Origin, лимит 5 заявок за 10 мин / 20 в сутки с IP, фильтр ссылок, обязательное согласие на обработку ПД с сохранением даты и редакции текста.
- Загрузка фото: проверка типа по содержимому, перекодирование через GD (вырезает вложенный код), случайные имена файлов, запрет выполнения скриптов в `uploads/`.
- `.env`, исходники и служебные папки вне корня сайта; скрытые файлы → 404.
- CSV-выгрузка защищена от инъекции формул Excel.

> Если сайт будет за Cloudflare или другим прокси, все посетители придут с IP прокси — лимиты на формы сработают на всех сразу. В этом случае настройте `client_ip()` в `app/lib/Helpers.php` на доверенный заголовок прокси (`CF-Connecting-IP`).

## API

- `GET /api/products/` — JSON-каталог. Параметры: `category`, `size[]`, `material[]`, `color[]`, `brand[]`, `price_min`, `price_max`, `wheels`, `in_stock`, `sort` (`price_asc`, `price_desc`, `new`). Лимит 120 запросов в минуту с IP. Подходит для выгрузки на маркетплейсы и интеграций.
- `POST /api/lead/` — приём заявок (JSON или обычная форма), используется формами сайта.
