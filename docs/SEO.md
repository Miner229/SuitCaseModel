# SEO и аналитика: что сделано и что настроить после запуска

## Структура страниц под поисковые запросы

| Тип запроса | Пример запроса | Страница | URL |
|---|---|---|---|
| Общий коммерческий | купить чемодан, чемоданы казахстан | Главная | `/` |
| Каталог | чемоданы цены, каталог чемоданов | Каталог | `/catalog/` |
| По размеру | чемодан ручная кладь 55×40×20 | Категория | `/catalog/ruchnaya-klad/` |
| | средний чемодан, чемодан M | | `/catalog/srednie/` |
| | большой чемодан, чемодан L / XL | | `/catalog/bolshie/` |
| | набор чемоданов 3 в 1 | | `/catalog/nabory/` |
| Товарный | чемодан aero lite s черный | Карточка товара | `/product/<chpu>/` |
| **Региональный** | чемоданы алматы, купить чемодан астана | Городская посадочная | `/almaty/`, `/astana/` … 18 городов |
| Информационный | как выбрать чемодан, какой размер чемодана нужен | Статья, блог | `/kak-vybrat-chemodan/`, `/blog/…/` |
| Транзакционный | доставка чемодана шымкент | Доставка + город | `/dostavka-i-oplata/`, `/shymkent/` |

Каждый город получает: H1 «Чемоданы в Алматы», title/description с городом в нужном падеже, уникальный вводный текст,
срок доставки, микроразметку `Store` с `areaServed: City`, форму заявки с автоматической подстановкой города
и перелинковку на другие города. Тексты и метатеги меняются в **Админке → SEO**.

> Чтобы городские страницы не посчитали «дорвеями», со временем добавляйте в каждую уникальное содержание:
> адрес пункта выдачи, отзывы клиентов из этого города, особенности доставки.

## Техническая SEO-оптимизация (готово, покрыто автотестами)

- ЧПУ латиницей, один адрес у страницы: 301-редиректы со слэшем/без, регистра, `index.php`, http→https, www→без www.
- `<title>`, `description`, один `<h1>`, `canonical`, Open Graph — уникальные на всех 52 страницах.
- Страницы фильтров и сортировок: `noindex, follow` + canonical на основной раздел (нет дублей).
- `sitemap.xml` — динамический, с `lastmod` и изображениями товаров; обновляется сам при изменении каталога.
- `robots.txt` — закрыты `/admin/` и `/api/`, `Clean-param` для UTM-меток (Яндекс). На тестовом стенде (`APP_ENV=development`) сайт закрыт полностью.
- Микроразметка schema.org (JSON-LD): `Store`, `WebSite`, `FAQPage`, `Product` + `Offer` (цена в KZT, наличие), `BreadcrumbList`, `ItemList`.
- Хлебные крошки, `alt` у всех изображений, `lang="ru"`, `og:locale=ru_KZ`, `geo.region=KZ`.
- Корректные коды ответа: 404 для несуществующих страниц и снятых товаров.
- Скорость: LCP ≈ 0,5 с на эмуляции слабого телефона, страницы 90–160 КБ, WebP + `srcset`, ленивая загрузка, нет внешних шрифтов и библиотек.

## Инструменты SEO в админке

| Задача | Где |
|---|---|
| Метатеги, H1 и тексты главной и информационных страниц | Страницы |
| Метатеги, H1, вводный и SEO-текст категорий и городов; новые города и категории | Категории и города |
| Метатеги товара, alt фото, закрыть товар от индексации | Товары → Изменить |
| Статьи под информационные запросы (с перелинковкой на каталог) | Блог |
| Сохранение позиций при смене адресов и удалении страниц, переезд со старого сайта | Редиректы (часть создаётся автоматически) |
| Яндекс Метрика, Google Analytics 4, Google Tag Manager, верификация Вебмастера и Search Console | Настройки |

Автоматически, без участия заказчика: sitemap.xml (с картинками и статьями), robots.txt, canonical, микроразметка (товары, хлебные крошки, FAQ, статьи), noindex на фильтрах, 301-редиректы при смене ЧПУ.

> Google Tag Manager: сайт защищён политикой CSP. Стандартные теги Google (GA4, Ads) работают; «пользовательские HTML-теги» сторонних сервисов могут блокироваться — их домены нужно добавить в `app/lib/Security.php`.

## Яндекс Метрика

1. metrika.yandex.ru → «Добавить счётчик» → адрес сайта, включить **Вебвизор**, **Электронная коммерция** (контейнер `dataLayer`).
2. Номер счётчика вписать в **Админке → Настройки → Номер счётчика**. Код подключится на всех страницах автоматически.
3. Создать цели типа **«JavaScript-событие»** с идентификаторами:

| Идентификатор | Когда срабатывает |
|---|---|
| `lead_any` | любая успешно отправленная заявка (**основная цель для Директа**) |
| `lead_order` | заказ товара из карточки / каталога |
| `lead_callback` | заявка «Перезвоните мне» |
| `lead_consult` | заявка «Подобрать чемодан» (главная, города, контакты) |
| `lead_popup` | заявка из попапа со скидкой |
| `open_order`, `open_callback` | открыли форму (для воронки) |
| `click_phone`, `click_whatsapp`, `click_telegram`, `click_email` | клики по контактам |
| `catalog_filter` | использование фильтров каталога |
| `popup_shown` | показан попап со скидкой |

4. Проверка: открыть сайт с `?_ym_debug=1` и отправить заявку — в консоли браузера будут видны отправленные цели.

## Яндекс Вебмастер

1. webmaster.yandex.ru → добавить сайт `https://ваш-домен.kz`.
2. Подтвердить права: способ «Мета-тег» → скопировать тег целиком в **Админку → Настройки → Код Яндекс Вебмастера** → «Проверить».
3. **Индексирование → Файлы Sitemap** → добавить `https://ваш-домен.kz/sitemap.xml`.
4. **Представление в поиске → Региональность** → указать **Казахстан** (или город магазина, если продаёте в основном там).
5. **Индексирование → Переезд сайта** → убедиться, что главное зеркало — `https://` без `www`.
6. **Индексирование → Переобход страниц** → отправить главную, каталог, категории и города.
7. Через 3–7 дней проверить «Страницы в поиске» и «Диагностика».

## Google Search Console

1. search.google.com/search-console → «Добавить ресурс».
   - Рекомендуется **«Доменный ресурс»** с подтверждением через DNS (TXT-запись у регистратора домена) — охватывает http/https/www.
   - Или «Ресурс с префиксом URL» → «HTML-тег» → вставить тег в **Админку → Настройки → Код Google Search Console**.
2. **Файлы Sitemap** → `sitemap.xml`.
3. **Проверка URL** → запросить индексирование главной и категорий.
4. Через неделю проверить «Индексирование страниц» и «Улучшения» (товары, хлебные крошки, FAQ).

## Локальное продвижение (рекомендуется, вне сайта)

- **2ГИС** — в Казахстане это основной картографический сервис; создать карточку организации со ссылкой на сайт.
- **Яндекс Бизнес** и **Google Business Profile** — карточки компании с адресом, телефоном, часами работы.
- Kaspi Магазин — при желании выгрузить каталог (можно на основе `/api/products/`).
- Казахская версия сайта (`/kk/` с `hreflang`) — можно добавить вторым этапом, если нужен трафик по запросам на казахском.
