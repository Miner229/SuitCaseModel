# Тестирование

## Как запустить

```bash
# 1. Локальный стенд (тестовая БД!) + мок Telegram API
php -S 127.0.0.1:8099 tests/mock/telegram.php &            # в .env: TELEGRAM_API_BASE=http://127.0.0.1:8099
php -S localhost:8000 -t public public/router.php &

# 2. Функциональные HTTP-тесты (123 проверки)
php tests/smoke.php http://localhost:8000

# 3. Браузерные тесты: адаптивность, интерфейс, скорость (60 проверок, скриншоты в tests/screenshots/)
node tests/e2e.js http://localhost:8000

# 4. После выкладки на домен (только чтение, безопасно для боевого сайта)
php tests/postdeploy.php https://ваш-домен.kz
```

`smoke.php` и `e2e.js` создают и удаляют тестовые товары и заявки — **не запускайте их на боевой базе**.

### Найдено и исправлено в ходе тестирования
1. Сортировка «сначала дешевле/дороже» нарушалась товарами «под заказ», которые всегда уходили в конец — теперь это правило действует только для сортировки «по популярности».
2. На экранах 320 px заголовок главной обрезался справа (картинка задавала минимальную ширину колонки, а `overflow-x:hidden` это маскировал) — исправлено во всех сетках; тест адаптивности усилен, чтобы ловить такие случаи.
3. `/.git/config` и другие скрытые пути отдавали 301 вместо 404 — теперь всегда 404.
4. Версия PHP светилась в заголовке `X-Powered-By` — убрана.
5. Таблица товаров в админке на телефоне требовала горизонтальной прокрутки — переделана в карточки.

## Что можно проверить только на боевом домене (чек-лист сдачи)

Сначала `php tests/postdeploy.php https://ваш-домен.kz` — он проверит SSL, редиректы, зеркала, robots/sitemap для домена, счётчики, закрытые файлы и все ссылки. Затем вручную:

- [ ] SSL: в браузере замок, нет «смешанного содержимого».
- [ ] Отправить заявку с телефона (по одной из каждой формы) → сообщение пришло в Telegram, заявка есть в **Админке → Заявки**.
- [ ] Метрика: через 5–10 минут визит виден в «Посещения», цели `lead_any` и `lead_order` засчитаны; Вебвизор записывает.
- [ ] Вебмастер и Search Console: права подтверждены, sitemap принят без ошибок, регион — Казахстан.
- [ ] Проверить в **Safari на iPhone** и в **Firefox** (автотесты выполнялись в Chromium; Safari/Firefox в тестовом окружении недоступны). Ключевые сценарии: меню, фильтры, попап заказа, отправка заявки.
- [ ] PageSpeed Insights (pagespeed.web.dev) для главной, каталога и карточки — ожидается 90+ на мобильном.
- [ ] Проверка микроразметки: search.google.com/test/rich-results и webmaster.yandex.ru/tools/microtest — для карточки товара.
- [ ] Заказчик самостоятельно: войти в админку, сменить пароль, добавить товар со своим фото, изменить цену, скрыть товар.
- [ ] Заменить демо-данные: контакты, юр. лицо и БИН в **Настройках**, тексты политики и согласия (проверить с юристом), демо-товары и фото.
- [ ] Резервное копирование БД и папки `public/uploads/` включено в панели хостинга.
